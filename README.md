# Thank You, Darsh

A thank-you letter from Arnur (founder of Tora) to Darsh Singh Mann, after AI & Digital Bridge in Astana, October 2026.

Plain static site: `index.html` plus the seven panel photos in `photos/`. No build step.

## Updating

Edit `index.html`, then:

```
git add -A
git commit -m "Describe the change"
git push
```

Vercel redeploys www.thanksdarsh.org automatically on every push to `main`.

The full photo sets from 2 and 3 October live in Google Drive and are linked from the page, not stored here.
